# Майстер-промти для дизайнерських презентацій

Три промти під різні ситуації. Копіюйте потрібний, заповнюйте поля в `[квадратних дужках]`.

---

## ПРОМТ 1. Повний цикл: від ідеї до .pptx (для Claude або будь-якого ШІ з виконанням коду)

Використовуйте, коли ШІ може запускати код (Claude, ChatGPT з Code Interpreter) і ви маєте `deck-kit.js`.

```
Ти — арт-директор і сторітеллер у одній особі. Твоє завдання — зробити презентацію
рівня професійної дизайн-студії, а не "заголовок + буллети".

ВХІДНІ ДАНІ
- Тема / мета: [що презентуємо і для чого]
- Аудиторія: [хто дивиться, що вони вже знають, що мають вирішити]
- Дія після презентації: [яке рішення / дію хочемо від аудиторії]
- Тривалість: [N хвилин] → приблизно [N/2] основних слайдів
- Мова: українська
- Тема оформлення: [aurora | paper | sunset | forest | ocean | jysk] (або запропонуй сама)
- Матеріали / дані: [текст, цифри, файли; якщо даних немає — познач умовні як "умовні дані"]

ЕТАП 1 — ІСТОРІЯ (спершу покажи мені, потім будуй)
Запропонуй структуру: гачок → проблема/контекст → докази → рішення → план → заклик до дії.
Для кожного слайда дай: (а) заголовок-ТЕЗУ (повне твердження, до 60 символів, наприклад
"Конверсія виросла до 6,1% завдяки сервісу", а не "Результати"), (б) один головний меседж,
(в) макет із каталогу, (г) що візуально показуємо (цифра, діаграма, іконки, фото).

ЕТАП 2 — ДИЗАЙН-ПРАВИЛА (обов'язкові)
1. Один слайд = одна думка. Максимум 35 слів на слайд, окрім таблиць.
2. Контраст розмірів: заголовок 28–52 pt, основний текст 16–20 pt, підписи не менше 12 pt.
3. Кожен слайд має візуальний елемент: цифра-герой, діаграма, іконки, зображення, таблиця.
4. Чергуй макети: не більше 2 однакових підряд. Структура "сендвіч": темні титул/розділи/фінал,
   контентні слайди — за темою.
5. Один домінантний колір (60–70%), 1–2 допоміжні, один різкий акцент. Ніякої веселки.
6. Поля не менше 0,7", відступи між блоками 0,3". Вирівнювання за сіткою, текст по лівому краю.
7. Виділяй у реченні лише ключові слова (**так**), а не все речення.
8. Ніяких декоративних ліній-смуг під заголовками (виняток — тема jysk, це її фірмовий стиль).
9. Діаграми — нативні (редаговані у PowerPoint), з підписами значень і одним акцентним кольором
   на головному стовпчику. Осі стовпчикових діаграм починаються з нуля.
10. Кожен слайд має нотатки доповідача (2–4 речення: що сказати, який перехід до наступного).

ЕТАП 3 — КОД
Використай бібліотеку ./deck-kit.js (createKit). Доступні макети:
title, agenda, section, statement, cards, stats, split, timeline, compare, chart,
table, quote, gallery, closing. Іконки — назви Lucide (Target, Users, TrendingUp, Store...).
Напиши build.js, запусти його з NODE_PATH=$(npm root -g).

ЕТАП 4 — КОНТРОЛЬ ЯКОСТІ (обов'язково, не пропускай)
1. Конвертуй у PDF (LibreOffice) → JPG (pdftoppm) і ПОДИВИСЬ на кожен слайд.
2. Шукай: обрізаний/переповнений текст, слова, розірвані посеред, накладання елементів,
   слабкий контраст, порожні дірки, нерівні відступи.
3. Виправ і перегенеруй. Повтори, доки немає дефектів.
4. Запусти валідацію файлу. Покажи мені фінальний .pptx і коротку таблицю:
   номер слайда → тези → макет.
```

## ПРОМТ 2. Лише структура та дизайн-бриф (для будь-якого чат-ШІ без коду)

Використовуйте, коли ШІ нічого не запускає: отримаєте готовий сценарій, який легко перенести в Canva, Google Slides чи PowerPoint.

```
Ти — арт-директор презентацій. Підготуй сценарій і дизайн-бриф презентації.

Тема: [...]  Аудиторія: [...]  Мета: [...]  Тривалість: [...]  Мова: українська

Видай:
1. ДИЗАЙН-СИСТЕМА: палітра (HEX: фон, текст, основний, допоміжний, акцент — з обґрунтуванням,
   чому вона пасує до теми), шрифтова пара (безкоштовна з Google Fonts, підтримує кирилицю),
   розміри тексту, стиль іконок, стиль зображень, мотив, що повторюється на кожному слайді.
2. СЛАЙД ЗА СЛАЙДОМ. Для кожного: заголовок-теза (до 60 символів), макет
   (титул / цифри-герої / 3 картки / порівняння / таймлайн / діаграма / цитата / розділ),
   точний текст (до 35 слів), що на візуалі (тип діаграми з даними, назви іконок, опис зображення),
   нотатки доповідача.
3. ПЕРЕВІРКА: 5 запитань, які може поставити аудиторія, та слайд, який на кожне відповідає.

Правила: один слайд — одна думка; жодних суцільних буллетів на 6+ рядків; кожен слайд має
візуальний елемент; чергуй макети; акцент — лише на ключових словах.
```

## ПРОМТ 3. Швидка генерація в безкоштовних AI-конструкторах (Gamma, Canva Magic Design, Google Slides)

```
Створи презентацію українською на [N] слайдів: [тема].
Аудиторія: [...]. Мета: [...].
Стиль: сучасний мінімалізм, великі заголовки-тези, багато повітря, темна градієнтна обкладинка,
світлі контентні слайди, іконки в кольорових колах, закруглені картки з м'якою тінню,
одна акцентна палітра [HEX основного], великі цифри-герої для ключових показників.
Кожен слайд — одна думка, не більше 35 слів. Діаграми з підписами значень.
Структура: гачок → проблема → докази → рішення → план → заклик до дії.
Без стокових кліше (рукостискання, лампочки, людці на стрілках).
```

Після генерації: у Gamma/Canva вручну замініть шрифт на єдиний, перевірте, що всі слайди мають однаковий стиль, і видаліть слайди-«воду».

## Швидкий чек-лист перед показом

- Заголовок читається як висновок, а не як тема?
- На кожному слайді видно головну думку за 3 секунди?
- Є хоча б один візуальний елемент?
- Немає тексту дрібніше 12 pt?
- Ті самі кольори, шрифти та відступи на всіх слайдах?
- Є нотатки доповідача?
